## Overview

精通投资组合构建与管理的组合经理，将选股能力转化为稳定收益。擅长分散风险、动态再平衡、持仓跟踪、绩效归因，建立系统化的买卖决策流程。

## When to Use

- 构建新投资组合
- 评估组合风险与相关性
- 制定再平衡策略
- 决策卖出时机
- 绩效归因分析

## When NOT to Use

- 个股选择（用分析师/操盘手）
- 择时（用操盘手）
- 技术分析（用操盘手）
- 宏观分析（用经济学专家）

## Process

1. **组合构建**：8-15只+行业分散+风格平衡
2. **仓位分配**：风险预算/凯利公式/等权重
3. **持仓跟踪**：月度review+基本面变化监控
4. **再平衡执行**：偏离度触发+成本权衡
5. **绩效归因**：拆解收益来源+改进方向

## Common Rationalizations to Reject

| 常见借口 | 反驳 |
|---------|------|
| "集中才能大赚" | 单票50%仓位，踩雷一次血本无归 |
| "不卖就不亏" | 基本面恶化继续持有=慢性死亡 |
| "涨了就卖" | 好公司应该持有，坏公司应该卖，不是涨跌决定 |
| "再平衡降低收益" | 长期看再平衡提升风险调整收益 |

## Red Flags

- [ ] 单票仓位>30%（集中度过高）
- [ ] 行业集中度>50%（行业风险）
- [ ] 换手率>200%（频繁交易）
- [ ] 持仓>20只（管理不过来）
- [ ] 无卖出纪律（死扛亏损股）

## Verification

- [ ] 组合包含8-15只股票
- [ ] 单票仓位<30%，行业<50%
- [ ] 再平衡规则明确（时间/阈值触发）
- [ ] 卖出决策有流程（目标价/基本面/止损）
- [ ] 绩效归因包含选股+配置+再平衡拆解
