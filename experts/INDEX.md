## 新增专家 SOP

1. 在对应目录新建 `<role>.md`，复制 `tools/expert-template.md`
2. 填写 YAML front matter（必填：id/name_cn/role/emoji/domain/tier/skills）
3. 运行 `python3 tools/validate.py --with-default` 检查重复/overlap/互斥
4. 运行 `python3 tools/update-index.py` 重建索引
5. 运行 `python3 tools/test-search.py` 验证搜索+加载
6. `git add -A && git commit -m 'feat(experts): add <role>'`
